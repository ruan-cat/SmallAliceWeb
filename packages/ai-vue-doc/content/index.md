# AI 对话组件

`@ruan-cat-drill-doc/ai-vue` 提供一个可在客户端交互的 AI 对话界面，用于展示固定的本地 mock 对话流程。

一期支持发送用户消息、追加本地 mock 助手回复，以及回复期间的 loading 与发送禁用状态。所有消息都在前端内存中处理，便于在文档站中稳定演示交互状态。

## 1. 一期边界

本阶段不包含真实 LLM、RAG、API key、模型配置、Nitro 路由、向量库或真实网络请求。该组件不调用外部服务，也不提供 `baseUrl` 等连接配置。

后续能力将在独立文档中说明。
