# 快速开始

`@ruan-cat-drill-doc/ai-vue` 提供本地 mock 对话组件。完成安装、样式导入和插件注册后，即可在 Vue 应用中使用。

## 1. 安装组件

在 Vue 项目中安装组件包：

```bash
pnpm add @ruan-cat-drill-doc/ai-vue
```

## 2. 导入样式并注册插件

在应用入口导入组件样式，并通过 `app.use(AiVue)` 注册组件：

```ts
import { createApp } from "vue";
import AiVue from "@ruan-cat-drill-doc/ai-vue";
import "@ruan-cat-drill-doc/ai-vue/styles";
import App from "./App.vue";

const app = createApp(App);

app.use(AiVue);
app.mount("#app");
```

## 3. 使用对话组件

注册后，可以在页面模板中直接使用 `AiChat`：

```vue
<template>
	<AiChat />
</template>
```

组件会在浏览器端维护本地 mock 消息状态，适合在文档站中演示基础对话交互。
