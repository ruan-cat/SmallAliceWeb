# AiChat 对话组件

`AiChat` 是一个固定尺寸的本地 mock 对话窗口。它在浏览器内维护消息、回复中的 loading 状态和发送禁用状态，适合用于组件演示与前端交互验证。

## 1. 基础用法

在 Nuxt 文档页中，将交互组件放在 `<ClientOnly>` 内，以保留稳定的 SSR shell，并在客户端挂载后启用交互。

::ai-chat-basic-demo
::

```vue
<template>
	<ClientOnly>
		<AiChat :initial-messages="initialMessages" placeholder="输入问题" :mock-delay="300" @send="handleSend" />
	</ClientOnly>
</template>

<script setup lang="ts">
import type { AiChatMessage } from "@ruan-cat-drill-doc/ai-vue";

const initialMessages: AiChatMessage[] = [
	{
		id: "assistant-1",
		role: "assistant",
		content: "这是本地 mock 对话。",
	},
];

/** 接收已发送的用户消息。 */
function handleSend(message: AiChatMessage) {
	console.info("已发送本地消息：", message.content);
}
</script>
```

## 2. Props

|       属性        |                          说明                          |       类型        |     默认值     |
| :---------------: | :----------------------------------------------------: | :---------------: | :------------: |
| `initialMessages` | 初始消息列表；每条消息包含 `id`、`role` 与 `content`。 | `AiChatMessage[]` |      `[]`      |
|   `placeholder`   |                    输入框占位文本。                    |     `string`      | `"请输入消息"` |
|    `mockDelay`    |           本地 mock 助手回复前的等待毫秒数。           |     `number`      |     `300`      |

## 3. 事件

|  事件  |                说明                |         回调参数         |
| :----: | :--------------------------------: | :----------------------: |
| `send` | 用户输入有效消息并触发发送时调用。 | `message: AiChatMessage` |

事件在用户消息写入本地状态后触发。回复内容仍由组件内部的固定本地 mock 流程追加，不依赖外部服务。

## 4. Mock 行为

1. 空白输入不会发送，发送按钮保持禁用。
2. 发送有效消息后，组件立即追加用户消息并显示“正在回复...”。
3. 回复期间，输入框和发送按钮都会禁用，避免重复提交。
4. 到达 `mockDelay` 后，组件追加固定格式的本地 mock 助手回复并恢复发送能力。

一期仅覆盖上述前端内存交互，不提供真实服务连接、知识检索、密钥、模型或网络请求配置。

## 5. 客户端渲染

组件本身不在模块顶层访问浏览器 API。对于 Nuxt 与 VitePress 的交互演示，仍建议将 `AiChat` 或悬浮入口包裹在各自的 client-only 边界中：这样服务端只输出稳定页面外壳，客户端挂载后再处理输入、发送和 mock 回复。
