## 5. 关键修复：shim instanceof 分派（重要发现）

初版 shim 按 design §3.1 用 `Object.setPrototypeOf(Canvas.prototype, HTMLCanvasElement.prototype)`，实测**静默不生效**：`@napi-rs/canvas` 的 Canvas 实例原型链为 `CanvasElement → Object`（napi 内部原型，不受 setPrototypeOf 影响），导致 `canvas instanceof HTMLCanvasElement` 为 false → `exportCanvasToPngDataUrl` 返回 null → 转换失败。

修复：在 HTMLCanvasElement 空类上定义 `Symbol.hasInstance`（`candidate instanceof Canvas`），instanceof 分派成立。Node 22 + @napi-rs/canvas 1.0.7 实测通过。design.md §3.1 已同步更新。

教训（继 `external-api-research-verify-dist` 之后再证）：**原型链操作对 napi 类不可靠，任何 instanceof hack 必须先写最小探针实测**。
