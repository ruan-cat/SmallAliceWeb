# 2026-08-28 Embedding 模型小样本对照

## 1. 实验边界

- 固定 50 个真实非空 chunks，来源为 `docs/docx`，稳定 ID 写入 JSON 证据。
- 固定题集 10 题，补充 2 个中英混合题，共 12 题。
- 对照模型：`@cf/baai/bge-m3` 与 `@cf/qwen/qwen3-embedding-0.6b`。
- 两个模型均使用 1024 维；只在内存中计算 cosine 排序，不写入 Neon `documents`/`chunks` 正式表。

## 2. 汇总结果

| :-----------------------------: | :----------: | :-----------: | :---------------------: | :-----------: | :---------------------: |

| `@cf/qwen/qwen3-embedding-0.6b` |     9/12     |    0.7500     |         0.3056          |    0.5833     |         0.3194          |

完整逐题结果、检索 ID 和固定 chunk ID 见同目录 `2026-08-28-embedding-model-smoke.json`。

## 3. 判断

qwen3 在本次 50 chunks/12 题样本上的 vector 指标优于 bge-m3，且请求成功；但 hybrid 指标没有改善，样本规模和题目覆盖仍不足以证明全量迁移收益。当前决策：保留 bge-m3 作为生产基线，将 qwen3 标记为候选；继续补充更具代表性的中文/中英混合题后，再决定是否全量重嵌入。
