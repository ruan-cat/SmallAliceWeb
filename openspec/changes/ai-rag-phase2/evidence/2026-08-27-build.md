## 3. 根因与修复边界

首次 fresh build 在 `@ztl-uwu/nuxt-content` 的内部内容 API prerender 处报 `Invalid URL`，随后又暴露 `nuxt-og-image@5.1.13` 与当前 Nuxt 3/Nitro h3 1.x 运行时的 `sendError` 缺失导入。根因是仓库不提交 lockfile，而 `shadcn-docs-nuxt@1.1.9` 的 `nuxt-og-image` 范围把 Nuxt 4 的 `@nuxt/kit`/h3 2.x 解析进 Nuxt 3 应用。最终在根 `package.json` 增加 `pnpm.overrides.nuxt-og-image=5.1.9`，撤销临时 `prerender.ignore` 与 `ogImage.enabled=false`，保留真实内容 prerender 与 OG Image 运行时。

本证据只证明本地完整构建成功；Git 集成 Production deployment 仍需以最新 `main` checkout SHA 的 Vercel `Ready` 状态和生产浏览器回归作为 2.2.4 最终证据。
