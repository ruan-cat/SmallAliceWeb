使用步骤

  1. 把上方链接拖拽到浏览器书签栏（松手即完成安装）。
  2. 打开任意目标页面，点击书签栏中的「元素指认拾取器」书签，页面元素开始点亮。
  3. 点选目标元素，引用卡 JSON 自动复制到剪贴板；按 Esc 退出拾取模式。
本地开发（VitePress dev server）会自动注入并点亮拾取器，无需安装书签；本页书签用于生产站点等未自动点亮的场景，手动触发。

脚本加载失败。请手动安装：

  1. 脚本路径：/element-picker.js（与本页面同目录）。直接在浏览器新标签打开它，复制全部内容。
  2. 在浏览器书签管理器里新建书签，名称随意，网址粘贴 javascript: 后接脚本全文。
  3. 在目标页面点击该书签即可点亮拾取器。

提示：若本页是通过 file:// 协议直接打开的，浏览器会拦截 fetch；请改用 HTTP 服务访问本页（例如 VitePress dev server 的 /element-picker-install.html）。
