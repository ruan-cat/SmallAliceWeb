# tweakcn - shadcn/ui 可视化主题编辑器

tweakcn 是一个用于 tailwind CSS 和 shadcn/ui 组件的视觉主题编辑器。它提供精美的主题预设，同时支持对 UI 各个方面的深度自定义。

## 功能

- **可视化主题编辑**：无需代码即可调整 shadcn/ui 组件的样式
- **主题预设**：内置多种精美主题预设，快速上手
- **深度自定义**：针对 UI 的每个方面提供高级定制选项
- **组件变体**：探索无限自定义选项并为组件添加个人风格
- **导出配置**：一键导出主题配置用于项目

## 使用方式

访问 https://tweakcn.com 使用在线编辑器，或参考项目中已克隆的源码进行本地开发。
